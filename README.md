# Проект «Мини-Склад»

Учебная конфигурация на платформе «1С:Предприятие 8.3».

## Состав конфигурации

- Подсистема: Мини-Склад
- Справочники: Товары, Контрагенты
- Документы: Поступление, Реализация
- Регистры накопления:
  - ОстаткиТоваров — учёт количества и стоимости товаров по партиям поступления, списание по FIFO.
  - Продажи — оборотный регистр продаж по товарам и контрагентам; ресурсы: Количество, Сумма, Себестоимость.
- Регистр сведений:
  - ЦеныНоменклатуры — цены товаров; периодичность — день, режим записи — независимый; измерение: Номенклатура, ресурс: Сумма (цена).
- Общие модули:
  - РаботаСЦенами — функция `ПолучитьЦенуНоменклатурыНаДату` возвращает последнюю установленную цену товара на дату документа (0, если цена не задана).
    Функция `ПолучитьЦеныНоменклатурыНаДату` возвращает цены списка товаров одним запросом (соответствие «товар → цена»).
  - РаботаСЦенамиТЧ — процедура `РассчитатьСуммуСтроки` считает сумму строки как Цена × Количество.
  - РаботаСПодборомТоваров — общий код форм Поступления и Реализации: добавление подобранных товаров в табличную часть и условное оформление незаполненных полей.
- Отчёт: ОборотыПоТоварам — отчёт на системе компоновки данных по виртуальной таблице Продажи.Обороты; показывает количество и сумму продаж по товарам и контрагентам за выбранный период.

## Возможности документов

Поступление и Реализация работают одинаково:

- **Подбор товаров.** Кнопка «Подбор» в табличной части открывает форму подбора справочника «Товары» с множественным выбором. Выбранные товары добавляются в документ; если товар уже есть в таблице, его количество увеличивается на единицу.
- **Автозаполнение цены.** Цена подставляется из регистра ЦеныНоменклатуры на дату документа при подборе и при изменении товара в строке. Сумма строки пересчитывается при изменении количества или цены.
- **Условное оформление.** Поля «Количество», «Цена» и «Сумма» в табличной части подсвечиваются красным, если значение меньше или равно нулю.
- **Проверка заполнения.** Обязательны контрагент, непустая табличная часть и товар в каждой строке. Количество, цена и сумма должны быть больше нуля. Сообщение об ошибке привязано к конкретной строке и полю.

Перед работой с документами задайте цены: раздел «Мини-Склад» — «Цены номенклатуры». Для товара без цены в документе подставится 0, и документ не пройдёт проверку заполнения.

## Структура репозитория

- `/src/` — исходные файлы конфигурации.
- `/src/AccumulationRegisters/` — регистры накопления «ОстаткиТоваров» и «Продажи».
- `/src/InformationRegisters/` — регистр сведений «ЦеныНоменклатуры».
- `/src/CommonModules/` — общие модули «РаботаСЦенами», «РаботаСЦенамиТЧ» и «РаботаСПодборомТоваров».
- `/src/Catalogs/` — справочники «Товары» (с формой подбора), «Контрагенты».
- `/src/Documents/` — документы «Поступление», «Реализация».
- `/src/Reports/` — отчёт «ОборотыПоТоварам».
- `/src/Subsystems/` — подсистема «Мини-Склад» с настройками интерфейса.
- `/src/Languages/` — язык интерфейса.
- `README.md` — описание проекта и инструкция по запуску.
- `.gitignore` — исключения для git (базы, логи, выгрузки `*.cf`/`*.cfe`, внешние обработки и отчёты, служебные файлы ОС и редакторов).

## Как открыть конфигурацию

1. Запустите 1С в режиме Конфигуратора с пустой информационной базой.
2. Меню: Конфигурация — Открыть конфигурацию.
3. Конфигурация — Загрузить конфигурацию из файлов... (выбрать папку `src`).
4. Нажмите F7 для обновления конфигурации базы данных.
