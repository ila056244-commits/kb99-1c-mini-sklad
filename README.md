# Проект «Мини-Склад»

Учебная конфигурация на платформе «1С:Предприятие 8.3».

## Состав конфигурации

- Подсистема: Мини-Склад
- Справочники: Товары, Контрагенты
- Документы: Поступление товаров, Реализация товаров
- Регистры накопления: ОстаткиТоваров

## Структура репозитория

- `/src/` — исходные файлы конфигурации (выгрузка в файлы XML).

## Как открыть конфигурацию

1. Запустите 1С в режиме Конфигуратора с пустой информационной базой.
2. Меню: Конфигурация — Открыть конфигурацию.
3. Конфигурация — Загрузить конфигурацию из файлов... (выбрать папку `src`).
4. Нажмите F7 для обновления конфигурации базы данных.
